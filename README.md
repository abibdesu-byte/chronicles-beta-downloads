1. Download and install the APK on Android 7.0 or later. Allow installation from your browser/file manager if asked.
2. Open **Chronicles Offline Beta**, tap **Play offline**, and create a local character. No login or server URL is needed.
3. Free cosmetics: **More → Fashion → Beta wardrobe**. Armor, weapon and wings mix independently. The Fallen Empire preview is included.

The offline app installs alongside the online beta. Progress stays on this device and does not sync online. Do not uninstall or clear app data if you want to keep it. Other-player multiplayer and chat require the online version. Android System WebView must be enabled. Tablet performance is still being tested.
